# 国补资料管理系统 - 使用教程

## 一、安装准备

### 1. 安装 .NET 8 运行时

本程序基于 .NET 8 开发，运行前需安装 **.NET 8 Desktop Runtime**。

下载地址：https://dotnet.microsoft.com/download/dotnet/8.0

选择 **.NET Desktop Runtime 8.x.x** 下载安装即可。安装后重启电脑。

> 如何检查是否已安装？打开命令行输入 `dotnet --list-runtimes`，看到 `Microsoft.WindowsDesktop.App 8.x.x` 即表示就绪。

### 2. 安装扫描仪驱动

程序通过 WIA（Windows Image Acquisition）接口调用扫描仪，需要：

1. 将扫描仪通过 USB 连接到电脑
2. 安装扫描仪厂商提供的驱动程序（从附带光盘或官网下载）
3. 打开 Windows 自带的「Windows 传真和扫描」验证扫描仪能正常工作

> 程序兼容大多数支持 WIA 的扫描仪。如果 Windows 自带扫描工具能用，本程序也能用。

### 3. 获取程序

将 `GuoBuZiLiaoGuanLi.exe` 复制到电脑任意位置即可，无需安装。

## 二、初次使用

### 第1步：启动程序

双击 `GuoBuZiLiaoGuanLi.exe` 启动。首次打开会显示欢迎页面。

### 第2步：选择根目录

点击「📁 选择根目录」按钮，选择一个文件夹作为**客户资料根目录**。

> **根目录是什么？** 程序会把所有客户文件夹放在这个根目录下管理。例如选择 `D:\国补资料`，之后每个客户的资料都会以子文件夹的形式存放在这里。

选择后程序会自动记住路径，下次启动无需重新选择。

### 第3步：了解文件夹状态

根目录下的每个子文件夹代表一个客户，程序会根据文件夹内容自动识别状态：

| 颜色 | 状态 | 含义 |
|------|------|------|
| 🔴 红色 | 缺资料 | 缺少必需的资料文件（发票/SN码/签购单/销售单） |
| 🟣 紫色 | 暂滞 | 资料不全，但已标记为暂缓处理 |
| 🔵 蓝色 | 未上传 | 资料齐全，等待上传到手机 |
| 🟠 橙色 | 未确认 | 已标记上传，等待电脑端确认 |
| 🟢 绿色 | 已上传 | 资料已上传并确认完成 |

### 第4步：了解资料类型

每个客户文件夹需要包含以下 4 类资料：

| 资料类型 | 文件名前缀 | 说明 |
|---------|-----------|------|
| 发票 | `fp` | 如 `fp01.jpg`、`fp02.jpg` |
| SN码 | `sn` | 如 `sn01.jpg` |
| 签购单 | `qg` | 如 `qg01.jpg` |
| 销售单 | `xd` | 如 `xd01.jpg` |

程序会自动按前缀识别文件类型。支持 `.jpg` `.jpeg` `.png` `.bmp` `.gif` `.tiff` `.pdf` 格式。

## 三、日常操作

### 1. 扫描资料

1. 在左侧列表点击选中一个客户文件夹
2. 在右侧「所需资料」区域，点击对应资料类型旁的「📷 扫描」按钮
3. 扫描仪将自动启动，扫描完成后文件会自动保存到客户文件夹中
4. 文件自动命名为 `fp01.jpg`、`fp02.jpg` 等递增编号

> **提示：** 如果没有扫描仪，程序会提示是否改为从文件选择图片。

### 2. 拖拽导入图片

1. 在左侧列表点击选中客户文件夹
2. 在右侧「所需资料」区域，点击选中一个资料类型（如「发票」），选中后高亮显示
3. 将图片文件（或从微信拖出的图片）直接拖到右侧预览区域
4. 文件自动保存并重命名

> **注意：** 预览区只允许在选中资料类型后拖入。支持从资源管理器、微信等来源拖拽。

### 3. 使用暂存区

暂存区用于临时存放尚未归类的文件，需要时再导入到客户文件夹。

1. 点击工具栏「📦 暂存」按钮打开暂存窗口
2. 可以通过以下方式添加文件到暂存区：
   - 拖拽文件到暂存区
   - 点击「📷 扫描添加」用扫描仪扫描
   - 点击「📁 添加文件」选择文件
3. 选中文件后可直接修改文件名作为备注
4. 需要归档时，在主界面选中客户文件夹 → 点击资料类型 → 点击「导入」按钮 → 从暂存区选择文件导入

> **暂存区文件导入后会自动从暂存区删除。**

### 4. 手机传输

通过 WiFi 局域网将资料下载到手机，无需数据线。

1. 确保手机和电脑连接**同一个 WiFi 网络**
2. 点击工具栏「📱 手机传输」按钮
3. 弹出二维码窗口，程序会自动启动 HTTP 服务并显示访问地址
4. 用手机扫描二维码，或在手机浏览器输入显示的地址（如 `http://192.168.1.100:8888`）
5. 手机端打开后可看到所有「资料齐全未上传」的文件夹列表
6. 点击「下载全部」将图片保存到手机相册
7. 下载完成后点击「标记已上传」，对应文件夹状态变为橙色

> **端口说明：** 默认使用 8888 端口，如果被占用会自动切换到 8080、9000 等端口。程序会自动添加 Windows 防火墙入站规则。

### 5. 确认上传

当手机端标记「已上传」后，电脑端该文件夹变为橙色（未确认状态）。

1. 在左侧列表找到橙色状态的文件夹
2. 点击右侧的「✓ 标记已上传」按钮
3. 文件夹变为绿色，表示该客户资料处理完成

### 6. 日期统计

1. 点击工具栏「📊 统计」按钮
2. 选择查询方式：
   - **单日查询**：选择一个日期，统计当天处理的客户数量
   - **日期范围查询**：选择开始和结束日期，统计区间内处理数量
3. 点击「🔍 查询」查看结果
4. 可点击「导出 Excel」将统计结果保存为 Excel 文件

> 统计依据是文件夹名称中的日期前缀（MMDD 格式），如 `0529-张三-手机` 表示 5月29日。

## 四、文件夹命名规则

程序通过文件夹名称解析客户信息和日期，建议按以下格式命名：

```
MMDD-姓名-商品          例如：0529-张三-手机
MMDD-姓名-商品已上传     例如：0529-张三-手机已上传
```

**支持的分隔符：** `-`、`_`、空格、`买`、`购`

例如以下名称都能正确解析：
- `0529-张三-手机`
- `0529张三买手机`
- `0529_张三_手机`

## 五、常用操作速查

| 操作 | 步骤 |
|------|------|
| 新建客户文件夹 | 在根目录下手动创建文件夹，命名格式 `MMDD-姓名-商品`，然后刷新 |
| 标记资料齐全 | 选中文件夹 → 点击「✓ 标记资料齐全」（资料不全时可用） |
| 标记暂滞 | 选中文件夹 → 点击「⏸ 标记暂滞」 |
| 取消暂滞 | 选中暂滞文件夹 → 点击「▶ 取消暂滞」 |
| 标记已上传 | 选中橙色文件夹 → 点击「✓ 标记已上传」 |
| 取消已上传 | 选中绿色文件夹 → 点击「↩ 取消已上传」 |
| 打开文件夹 | 选中文件夹 → 点击「📂 打开文件夹」 |
| 删除文件夹 | 选中文件夹 → 点击「🗑️」 |
| 搜索 | 在搜索框输入客户姓名或日期 |
| 筛选状态 | 点击左侧「全部/缺资料/暂滞/未上传/未确认/已上传」单选按钮 |
| 刷新列表 | 点击「🔄 刷新」或切换到其他窗口再切回来（自动刷新） |

## 六、常见问题

### Q: 程序打开后是空白页？
A: 首次使用需要点击「📁 选择根目录」选择一个文件夹。之后每次启动会自动加载上次选择的目录。

### Q: 扫描时提示"未检测到扫描仪"？
A: 请检查：
1. 扫描仪已通过 USB 连接并开机
2. 已安装扫描仪驱动
3. 打开 Windows 自带的「Windows 传真和扫描」测试是否能扫描
4. 如果仍不行，可以选择"从文件选择图片"代替扫描

### Q: 手机无法访问传输地址？
A: 请检查：
1. 手机和电脑是否连接同一个 WiFi
2. 电脑防火墙是否拦截（程序会自动添加规则，但部分安全软件可能仍会拦截）
3. 尝试关闭杀毒软件的防火墙后重试
4. 可以在手机浏览器手动输入地址访问

### Q: 拖拽图片到预览区没反应？
A: 必须先在右侧「所需资料」区域点击选中一个资料类型（如"发票"），选中后会蓝色高亮，然后才能拖入文件。

### Q: 从微信拖拽的图片无法识别？
A: 程序支持从微信拖拽图片，但某些版本可能使用特殊格式。如果拖拽无效，可以先将图片保存到电脑，再从文件夹拖入。

### Q: 扫描后文件名不对？
A: 程序会自动将扫描的文件重命名为对应前缀（如 `fp01.jpg`）。如果连续扫描多种资料，请确保每次扫描前点击正确的资料类型按钮。程序有扫描锁定，扫描期间所有扫描按钮会禁用并显示"扫描中..."。

### Q: 文件夹状态颜色不对？
A: 点击「🔄 刷新」按钮重新加载。程序会根据文件夹内的文件和标记文件自动判断状态。

## 七、配置文件位置

程序配置保存在以下位置：

```
C:\Users\{用户名}\AppData\Local\GuoBuZiLiaoGuanLi\config.txt
```

该文件记录了上次选择的根目录路径。删除此文件可重置程序配置。
